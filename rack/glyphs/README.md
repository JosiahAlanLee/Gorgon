# Panel glyph

Gorgon's panel carries mark XI, *Reflexive loop* ("the map moves it": Rack
follows Gorgon's clock and moves it back), one of the twelve Revision 3
sketching marks from *Clavicula Matricis* (Tabula XIII,
[Systems_Practice_Grimoire](https://github.com/JosiahAlanLee/Systems_Practice_Grimoire)).

`glyph.py` places a mark on a panel in the panel's colours; `tools/make_panel.py`
calls it. `render_glyphs.py` regenerates `markNN.svg` from a checkout of the
grimoire. Only `mark11.svg` is kept here; the full set, and the marks used by the
OTIS, Vastish and Spoon Bender panels, live in
[DSP_Emulation](https://github.com/JosiahAlanLee/DSP_Emulation/tree/main/vcv/shared/glyphs),
where this tool came from.
